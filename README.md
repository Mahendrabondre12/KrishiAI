# 🌾 KrishiAI

### AI-Powered Agricultural Intelligence Platform

KrishiAI is a multilingual, full-stack agricultural platform that combines **Google Gemini AI, live weather information, soil data, crop growth stages, and farm records** to provide farmers with practical and personalized recommendations.

---

## 🚀 Features

- 🤖 AI-powered farm recommendations
- 💬 Multilingual agricultural chatbot
- 🩺 Crop disease and pest image analysis
- 🌦️ Live weather and seven-day forecasts
- 🧪 Soil pH and NPK guidance
- 🌾 Farm and crop management
- 📅 Crop growth-stage tracking
- 📲 SMS and WhatsApp-ready farm updates
- 👨‍🌾 Expert case escalation
- 📊 Platform administration dashboard
- 🌐 English, Hindi, Marathi, Punjabi, Gujarati, Telugu, Tamil, Kannada, and Bengali support
